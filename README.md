Analysis of the relationship between ambient lighting, daylight saving
time, 911 calls, and reported crime across Austin, Hartford,
New Orleans, Seattle, and San Francisco.

The R scripts clean the source datasets, construct lighting
variables, and perform the statistical analysis. R scripts produce full reports and figures when run.

Created (not raw), cleaned datasets included. 'Processed' contains intermediate datasets for each cities crime and 911 call volume. 'Mega' contains the the final, merged (all five cities) crime and 911 datasets where each row is analyzed at the day level.
